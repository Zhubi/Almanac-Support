历年

一本可以翻的电子历书 · 支持页面

历年把公历的一天还原成传统历法里的一天：农历、节气、七十二候、每日宜忌与神煞，都附白话解释。

常见问题

宜忌、冲煞这些内容依据什么？
依据传统历书的通行排法，由本地历法算法计算，不需要联网。术语都配了白话说明，可以直接在主界面看到解释。

数据会上传吗？
不会。日历与黄历都在设备本地计算，我们不设服务器，也不收集你的使用数据。详见隐私政策。

小组件不更新怎么办？
先在系统设置里确认「历年」的后台刷新已开启；随后在小组件上长按 → 编辑小组件 → 重新选择一次即可。系统会在合适的时间刷新，长按小组件能看到上次更新时间。

会员包含什么？
会员解锁道历（道节日、三元八会、五腊）、无限次分享图生成，以及之后新增的扩展内容。订阅由 Apple 处理，可随时在「设置 → Apple ID → 订阅」里管理或取消。

换设备后记录还在吗？
本地设置会随 iCloud 备份恢复；如果开启 iCloud 同步，设置项会在同一 Apple ID 的设备间同步。
